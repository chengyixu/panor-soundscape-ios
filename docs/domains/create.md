# Create Domain

Create is an automatic pipeline rather than a collection of enrichment buttons:

1. Activating the Create tab requests when-in-use location permission and resolves one coarse place. Eager `TabView` construction must not prompt while another tab is visible.
2. Recording completion or audio import moves into review and immediately requests AI title/description.
3. The generated title drives automatic watermarked cover generation.
4. Generated text becomes editable and a photo-picker cover can override the AI cover.
5. Publishing validates one draft contract and uploads audio plus exactly one cover source.

Location denial is non-fatal. AI failures remain inline with the draft intact and expose one retry for the whole enrichment pipeline. The UI never requires a user to manually trigger location, title generation, or initial cover generation.
