# Soundscape iOS Release Checklist

## Automated gates

```bash
scripts/ci.sh
SOUNDSCAPE_VERIFY_LIVE=1 scripts/verify-api-contract.sh
```

The CI script regenerates the Xcode project, runs repository invariants, performs a signed clean stable-runtime simulator build, executes unit tests (including a real Keychain round trip), and navigates all five primary tabs through XCUITest. The live preflight verifies both Soundscape OpenAPI parity and the unified auth registration field contract.

## Bundle invariants

- Product and display name are `Soundscape`.
- Bundle identifier is `tech.panor.soundscape`.
- AppIcon is generated by `scripts/generate-app-icon.sh` and compiled into `Assets.car`.
- iPhone is the only targeted device family.
- Background audio is declared through `UIBackgroundModes = audio`.
- Microphone, location, and photo-library usage descriptions are present.
- Marketing and build versions come from `MARKETING_VERSION` and `CURRENT_PROJECT_VERSION`.

## Manual device checks

- Play a live item, background the app, reconnect headphones, and complete playback.
- Deny and then grant microphone permission; verify recording cleanup in both paths.
- Import a supported audio file and reject an oversized or unsupported file before publish.
- Select and normalize a cover, then verify AI covers display the opaque Soundscape label.
- Verify signed-out create/library behavior without inventing credentials.
- Run VoiceOver and Accessibility XXXL Dynamic Type through Explore, Map, Create, Rankings, and Library.

Production website analytics verification depends on its existing `gtag.js`; do not remove that script from the web deployment.
